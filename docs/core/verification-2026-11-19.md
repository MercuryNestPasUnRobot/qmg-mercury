## 2026-11-20 Core 完成验收

本轮复验覆盖架构设计书要求的 Core 及浏览器接入路径。结果见下表，历史记录保留于上文。

| 验收项 | 本轮证据 |
| --- | --- |
| 统一位置、地图与合法性 | Token 守恒、区域顺序、地形和占据约束。路径按建设、战斗、补给用途查询，持续状态只影响定义指定的用途 |
| 浏览器和 AI 接入 | 测试通过实际 HTTP 读取验收台、提交手牌和地区表单、查看分数及日志。AI 按相同 CoreAPI 提交。测试验证过期表单被拒绝 |
| 串行结算和回合末恢复 | 盖放、等待、揭示、支付、转移及国家推进均有记录。验收台核对上一对象完成时接续对象进入 RESPONSE，随后由接续对象进入 RESOLUTION 并以普通 TRANSFER 移动原单位。另测恢复后的监听、连续转移、非法目的地及回合末胜负时机 |
| 恢复与重放 | 测试强制结束独立 Python 进程，重新加载相同待决选择并续写日志。覆盖首条记录写入前中断、回合末待决选择、原记录前缀及结果哈希 |
| 可见信息与 AI | 对手盖放和放弃时隐藏身份，揭示后保留原先的权限投影。统一合法指令、确定性评分、隐藏牌序对照及模拟预算测试通过 |
| 综合检查 | `npm run check` 全部通过，含 70 项 Python Core 测试和 4 项 Node 服务测试。旧归档 1,725 文件及上游 347 文件核验一致 |

浏览器使用原创机制场景。正式游戏内容包和 AI 强度标定有各自的验收范围。
