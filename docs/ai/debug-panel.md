# AI 调试台

运行 `npm run core:ai-debug`，打开 [本机调试台](http://127.0.0.1:5186)。在「双方 AI 配置」中切换轴心和同盟，各自选择版本、A 规则或 B 搜索策略，并调整评分参数。支持 A 对 A、B 对 B 和混合策略。

- **单局测试**。打完一局自动停止。
- **同种子换边两局**。沿用同一个种子，第二局交换双方的版本、策略和全部参数，两局结束后停止。
- **连续换边测试**。每个种子打两局，然后种子加一。关闭浏览器页面后，本机服务仍会继续跑，直到点击「停止测试」或关闭服务。

「暂停测试」会等待当前决策完整结算，并停在下一次决策之前。暂停后可修改 VP、卡牌、行动等基础得分，也可展开其他评分参数。点击「单步执行」会应用当前输入，执行一次 AI 决策及随后的自动结算，并自动打开这一条的候选分数、实际选择、区域转移和 VP 变化。若结算产生新的选择，会停在该选择前。点击「应用参数」后保持暂停，点击「继续测试」会应用当前输入并续跑。每次成功修改都会产生一份参数记录，日志行显示该步使用的参数版本。

「复制本方」可以保存当前所选阵营的配置文本，「复制双方」会保存当前双方各自的配置。将文本放进「粘贴配置」即可载入。单方文本载入当前选中的阵营，双方文本按阵营载入。暂停时可以改版本、策略和参数，载入或编辑后通过「应用参数」「单步执行」或「继续测试」生效。

双方共用当前 Core 的对局规则和卡库。已登记的历史 AI 使用对应 Git 提交中的算法，并独立接收当前席位允许获得的观察与合法指令。没有本地卡库时显示「合成测试场景」。初始搜索上限与六席批次相同，B 的每次决策预算为 3 秒。参数记录保存双方各自的完整配置，决策日志注明执行者实际使用的版本和策略。

对局棋盘沿用录像台的本地底图和棋子样式。点击地区能看到驻军，切换国家能看到该席位的手牌、状态牌和响应牌。全席牌区源自本机裁判视图，AI 决策仍只观察各自席位允许知道的信息。每局保留最后一个棋盘快照，更新前生成的日志仍可查看评分。

「调试日志」按测试批次和对局选择，支持分别下载决策日志和参数记录。调试日志与棋盘快照都存于 `local-content/ai-debug/`。暂停续跑依赖本机服务和当前测试进程。如果地址无法打开，可在项目目录重新运行 `npm run core:ai-debug` 启动本机服务。
