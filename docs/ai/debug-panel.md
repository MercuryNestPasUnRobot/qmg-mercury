# AI 调试台

运行 `npm run core:ai-debug`，打开 [本机调试台](http://127.0.0.1:5186)。在「双方 AI 配置」中切换轴心和同盟，各自选择版本、A 规则或 B 搜索策略，并调整评分参数。支持 A 对 A、B 对 B 和混合策略。

## 玩家对局

在调试台点击「玩家对局」，选择阵营、一个真人席位和一张保存的地图。其余五席各自可以设置 AI 版本、A／B 策略和评分参数，也可以将当前设置一键应用到全部 AI、轴心 AI 或同盟 AI。辅助国仍由原来的席位控制。开局可填写种子复现实验，留空由本机生成。

棋盘显示驻军、相邻地区和可选目标。可用操作由 Core 提供，包含开局弃牌、出牌、响应、目标及效果选择、空军和调配。「调配资源」在本国回合开始、打出本回合的牌前出现。遇到真人可以介入的时机，对局会等你处理响应或交给 AI。公开出牌和已翻开的响应可以查看牌文。其他席位的手牌、盖放响应、牌库和弃牌只显示数量，公开状态牌可查看。自然结束的对局和手动结束的已进行对局，核对日志后自动进入录像台。名称包含「玩家对局」、开局时间、AI 配置概况和地图名。玩家录像沿用玩家视角。

标准地图和此次修正前保存的自定义地图补齐巴尔干与日耳曼之间的建设、战斗和补给连接。强制征兵按所选地图的日耳曼及其相邻地区判定陆军征召位置。已经开局的对局及其回放使用原本的规则快照。

新版空军阶段可以进行一次空军行动，或弃一张手牌，把一架已有飞机移到该军队所属国的另一个单位所在地区。两种操作共用一次机会。英美的常规空军牌只能用于本国空军，法国和中国的空军通过专门事件建设。调配资源成功后洗牌，包括由状态牌允许从弃牌堆取基本牌的情况。

## 地图编辑与切换

在「测试设置 → 对局地图」选择标准地图或已保存的地图，再点击「打开地图编辑器」。点地图标记或从地区列表选择一个地区，即可修改分点类型，新增、编辑或移除连接，并选定连接用于建设、战斗还是补给。修改海峡时选择一处控制陆地和两个海域。海峡会取代相同两海域间的普通连接，通行继续由 Core 的海峡规则决定。

输入新名称并保存，调试台会为下一局选中该地图。地图可以在下一次打开调试台时重新选择。每批对局都固定自己的地图快照与规则校验值，换边两局使用同一张地图。地图库和对局日志分别保存在本机。

在「初始单位布置」展开单位列表，选国家和具体单位，再点「放到当前地区」或「移回预备区」。地区标记上的数字是该地的初始单位数。陆军可放陆地，海军可放海域，Core 会检查每个地区的单位组合。开局后按正常补给规则结算。旧地图若没有保存单位布置，开局沿用卡库默认值。

## 当前对局规则

- 在一轮最后一个国家的摸牌及回合结束响应完成后，Core 检查两阵营的 VP 差。领先至少 31 VP 提前获胜。达到最大轮次时按实际分差结束。
- 敌方陆军占领一个国家当前的大本营后，该国家的单位停算其他地图分点。受该国家控制的隐分点也停止计分。苏联迁都后按新的大本营判定。辅助国按自己的大本营判定。
- 弃牌阶段完全没有弃牌时，Core 在摸牌前实际扣该国阵营 1 VP，并写入 `no-discard` 结算记录。弃过至少一张可免除该笔罚分。
- AI 基础得分中的主要国与辅助国大本营默认为 2 和 1。当前 A、B 共用这项位置估值，按当前大本营和到达距离计算。选择旧版 AI 时，可复用旧策略的估算行为，对局仍由当前 Core 裁定。

- **单局测试**。打完一局自动停止。
- **同种子换边两局**。沿用同一个种子，第二局交换双方的版本、策略和全部参数，两局结束后停止。
- **连续换边测试**。每个种子打两局，然后种子加一。关闭浏览器页面后，本机服务仍会继续跑，直到点击「停止测试」或关闭服务。

「暂停测试」会等待当前决策完整结算，并停在下一次决策之前。暂停后可修改 VP、卡牌、行动等基础得分，也可展开其他评分参数。点击「单步执行」会应用当前输入，执行一次 AI 决策及随后的自动结算，并自动打开这一条的候选分数、实际选择、区域转移和 VP 变化。若结算产生新的选择，会停在该选择前。点击「应用参数」后保持暂停，点击「继续测试」会应用当前输入并续跑。每次成功修改都会产生一份参数记录，日志行显示该步使用的参数版本。

「复制本方」可以保存当前所选阵营的配置文本，「复制双方」会保存当前双方各自的配置。将文本放进「粘贴配置」即可载入。单方文本载入当前选中的阵营，双方文本按阵营载入。暂停时可以改版本、策略和参数，载入或编辑后通过「应用参数」「单步执行」或「继续测试」生效。

调试台和玩家对局使用同一份 AI 版本列表。「当前工作区」随本机代码更新。v1.27、v1.28、v1.29 和先前登记的历史版本各使用对应 Git 提交的算法。双方共用当前 Core 的对局规则和卡库，各 AI 接收自己席位可见的观察与支持的合法指令。没有本地卡库时显示「合成测试场景」。初始搜索上限与六席批次相同，B 的每次决策预算为 8 秒。参数记录保存双方各自的完整配置，决策日志注明执行者实际使用的版本和策略。

对局棋盘沿用录像台的本地底图和棋子样式。点击地区能看到驻军，切换国家能看到该席位的手牌、状态牌和响应牌。全席牌区源自本机裁判视图，AI 决策仍只观察各自席位允许知道的信息。每局保留最后一个棋盘快照，更新前生成的日志仍可查看评分。

「调试日志」按测试批次和对局选择，支持分别下载决策日志和参数记录。调试日志与棋盘快照都存于 `local-content/ai-debug/`。暂停续跑依赖本机服务和当前测试进程。如果地址无法打开，可在项目目录重新运行 `npm run core:ai-debug` 启动本机服务。
