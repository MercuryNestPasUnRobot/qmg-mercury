# AI 调试台

运行 `npm run core:ai-debug`，打开 [本机调试台](http://127.0.0.1:5186)。在测试设置里选择 AI 版本、种子和 B 的首局阵营，再点击「开始测试」。

- **单局测试**。打完一局自动停止。
- **同种子换边两局**。A 和 B 使用同一个种子对换阵营，两局结束后停止。
- **连续换边测试**。每个种子打两局，然后种子加一。关闭浏览器页面后，本机服务仍会继续跑，直到点击「停止测试」或关闭服务。

「暂停测试」会等待当前决策完整结算，并停在下一次决策之前。暂停后可修改 VP、卡牌、行动等基础得分，也可展开其他评分参数。点击「应用参数」后保持暂停，点击「继续测试」会应用当前输入并续跑。每次成功修改都会产生一份参数记录，日志行显示该步使用的参数版本。

已登记的历史版本使用对应 Git 提交中的算法。工作区有该版本的本地卡库时会校验卡库指纹，缺少对应卡库时显示「合成测试场景」。初始搜索上限与六席批次相同，B 的每次决策预算为 3 秒。

「调试日志」按测试批次和对局选择，点步数可查看评分与候选方案。支持分别下载决策日志和参数记录。文件位于 `local-content/ai-debug/`，已关闭服务的测试保留日志。暂停续跑依赖本机服务和当前测试进程。
