# AI 评分基准 · v1.11

常规对局、玩法验证台和 A/B 对照试验共用 [AI 评分配置](../../core/data/ai_test_weights.json)。在 `scoring_units` 中修改下面四项即可调整基准。Core 的实际计分规则和日志中的实际 VP 独立于这组换算值。

| 字段 | 当前值 | 含义 |
| --- | ---: | --- |
| `vp` | 1 | 每 1 VP 对应 1 局势分 |
| `card` | 1 | 每张牌的基础价值为 1 局势分 |
| `action` | 2 | 一次完整行动机会对应 2 局势分 |
| `capture_rounds` | 2 | 占点时全额计入的回合数 |

## 占点的固定收益

A 把落子后新增的阵营每回合总收入乘以 2，再按 VP 换算。占领 2 VP 的空分点通常给 4 分，原有的路线、邻近敌军和建设拥挤估值另外计算。固定收益避开路线折扣和上限。移除对手单位沿用对称的估值。两个盟国共享同一 2 VP 分点时各得 1 VP，阵营总产出仍为 2 VP，因此第二席入驻带来的固定收益为 0。

B 按 Core 的计分规则，从结算后的局面读取每席还能获得的分点收入。接下来两轮的计分机会全额折算，之后的机会才应用原有的时间衰减、威胁和控点增益。已结算的 VP 进入实际得分，超出对局回合上限的机会取消。A 的占点评分同样受剩余回合上限限制，终盘可能少于 4 分。

## 已换算的项目

| 估值来源 | 现行表达 |
| --- | --- |
| 直接得失分、按公开单位或地区计算的分数、当前牌库耗尽或无牌可弃的扣分 | 实际 VP 数量 × VP 基准。即时结束对局的胜负继续优先排序。此前的即时 VP 加倍率留给旧评分配置。 |
| 经济战和未来缺牌 | 立即扣分按 VP 基准全额折算。未来缺牌仍按预计补牌次数和 0.6 的兑现比例估算。时限和双方距离获胜所需的分差仍影响展望长度。 |
| 建设、招募、战斗及空军行动 | 现有估值按行动基准的比例表达。A 的建陆、建海分别为 0.8、0.7 次行动。B 估算手中建陆、建海牌的能力分别为 0.5、0.4 次行动。纸面当场执行和手牌潜力保留各自的比例，同一种动作的原生与卡牌声明写法共用评分。 |
| 手牌、可确定的抽牌和支付 | 牌的基础库存按张数换算，牌效潜力另加。A 出牌扣一张牌的基础分，B 从结算前后手牌变化体现，同一次消耗计一次。主动换牌中的拥挤、保留和弃置权重以卡牌基准表达。 |
| 基础牌稀缺 | 弃牌时继续追加 `1.2 × 已打出的同类牌数 ÷ 固定编组同类牌数 × 卡牌基准`。常规出牌沿用既有处理。 |
| 状态牌 | 沿用有效时机、触发概率、剩余时间、同一时机的竞争和防重复计算。单次效果能按 VP、牌数或可用行动换算时使用对应基准。 |

## 保留原值，待明确含义后调整

| 位置 | 当前保留的假设 |
| --- | --- |
| 手牌或未细分效果的兜底 | 未知暗牌在基础库存之上另有 0.20 的牌效估值，未知纸面效果通常取 0.20 或 0.25。被收录但尚无专门公式的效果仍用配置中的估值。 |
| 交战和目标的补充分 | 单位类型的额外移除价值、旧战斗分 `battle_target`，以及通用地点选择的有驻军加 0.25。现有值无法确定对应多少 VP、牌或行动。 |
| 状态牌及牌序的局势差异 | 整理牌库顶每张 0.22，送至牌库底每张 0.28，尚无预计损失时自磨每张扣 0.06。准备就绪的规则修正加 0.35 或增援加 0.20 的估计也沿用原值。 |

距离、补给、友军密度、威胁和触发概率继续作为系数。强制选择、可跳过选项和确认按钮的排序值仍用于流程控制。
