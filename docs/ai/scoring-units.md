# AI 评分基准

常规对局、玩法验证台和 A/B 对照试验共用 [AI 评分配置](../../core/data/ai_test_weights.json)。在 `scoring_units` 中修改下面四项即可调整基准。Core 的实际计分规则和日志中的实际 VP 独立于这组换算值。

| 字段 | 当前值 | 含义 |
| --- | ---: | --- |
| `vp` | 1 | 每 1 VP 对应 1 局势分 |
| `card` | 1 | 每张牌的基础价值为 1 局势分 |
| `action` | 2 | 一次完整行动机会对应 2 局势分 |
| `capture_rounds` | 2 | 占点时全额计入的回合数 |

## v1.24 就绪能力

事件监听按当前地图、公开状态和本席可见手牌判断。基础牌相关能力在已知条件许可时，取可见匹配机会数和最低预计次数两者的较大值。最低值默认为一次，单次响应或增援至多计一次。其他事件只计能从可见信息判断的机会。固定时点按剩余合法窗口和当前条件计数，自由插入按可执行的效果估值。一次性能力仍按等待回合折算时间成本，只有可见联动能改善净收益时才推迟发动。

响应、增援和状态能力的空降落点采用地图位置价值，所有距离加一，敌军占据目标时该位置为零。评分直接使用落点，跳过单次事件征召的回合末留存核验。人民冲锋队按德国首都的普通征召位置计价，并依据当地能否征召计算机会。

## v1.23 弃牌、过牌与状态牌

| 项目 | 评分 |
| --- | --- |
| 弃牌 | 比较腾出补牌空间、避免扣 VP 等收益与放弃牌效的代价。基础牌额外按可达分点减少数乘以扩张偏好计价，覆盖固定、半分和隐分点。 |
| 过牌 | 每多抽一张按「牌值 − 当前可见手牌平均短期收益」计价。弃三找一比较直接出牌多腾出的实际补牌位，结算中的牌差单独计一次。 |
| 缺牌 | 预计缺牌按实际扣分一比一折算。经济战沿用每轮 4 VP 分差和实际剩余回合上限估算对局长度。 |
| 看牌和整理 | 看 n 张按一次 n 张的过牌收益计价。整理已揭示的牌先预测本回合自身出牌若会消耗牌库顶，并把较低分的牌排入预计弃置的位置。同等条件下，局面评分较高的牌置顶。预测使用可见手牌与模拟占位牌。 |
| 条件式状态牌 | 预估触发次数为可见匹配牌的可用次数加一次，受规则窗口和剩余回合限制。空降及路径变化沿用地图估值，各对象距离加一。 |
| 防护与补给 | 防移除按对应地区建设价值计算，地点未知时取一次行动机会。一次性无视补给按前后局势差值计分，永久效果另加一次行动机会。 |
| 其他状态效果 | 要求敌方弃牌按实际可弃数量计，每张默认一分。滤牌、未来进驻和条件维持等系数在 `status_forecast` 配置。 |

## v1.22 行动机会与落点

A 的纸面分和 B 的结算分都会在消耗机会时扣一次 `scoring_units.action`。普通出牌、主动使用状态牌、出牌阶段被迫弃牌或扣分、空军行动分别在指令入口计费。选目标、后续效果和响应沿用同一次结算。弃三找一在后续花掉出牌机会时扣一次。决策日志用 `action_cost` 单列这项。

建陆、建海、征召和手牌中的对应效果使用可达落点。B 在效果结算后核验单位留存，把每方对同一分点的最好持久位置与下一次收入合并计分。无补给单位的临时收益来自它实际赚到的 VP 或留下的地图结果。移除敌军保留一次行动的基础收益和地图变化。重部署按最佳合法落点减原位置评分。空军部署按目标位置估值，调动扣除原位置估值，制空战按实际可移除目标估值。Core 的空军计分和补给规则保持原样。

额外摸牌共用「每张牌的基础值减手牌平均短期收益」。手牌平均值计算时跳过摸牌效果自身，避免递归计价。B 的牌库存已经计入摸到的牌，所以只减去对应的平均收益来完成换算。正常摸牌阶段与牌库耗尽仍按实际规则结算。

旧的 `ability_ready` 是可发动能力副本的兜底价。能力是来源牌附带的规则对象，可用副本位于 `ABILITY_READY`，发动会把副本移出可用区。它与手牌张数分开。旧字段 `0.50` 按 `0.50 / 2 × 行动基准` 换算，在基准为 2 时每个副本是 0.50 局势分。已有专用预测的状态牌、延迟响应按可用时机和效果估值。

## 占点的固定收益

A 把落子后新增的阵营每回合总收入乘以 2，再按 VP 换算。占领 2 VP 的空分点通常给 4 分，原有的路线、邻近敌军和建设拥挤估值另外计算。固定收益避开路线折扣和上限。移除对手单位沿用对称的估值。两个盟国共享同一 2 VP 分点时各得 1 VP，阵营总产出仍为 2 VP，因此第二席入驻带来的固定收益为 0。

B 按 Core 的计分规则，从结算后的局面读取每席还能获得的分点收入。接下来两轮的计分机会全额折算，之后的机会才应用原有的时间衰减、威胁和控点增益。已结算的 VP 进入实际得分，超出对局回合上限的机会取消。A 的占点评分同样受剩余回合上限限制，终盘可能少于 4 分。

## 已换算的项目

| 估值来源 | 现行表达 |
| --- | --- |
| 直接得失分、按公开单位或地区计算的分数、当前牌库耗尽或无牌可弃的扣分 | 实际 VP 数量 × VP 基准。即时结束对局的胜负继续优先排序。此前的即时 VP 加倍率留给旧评分配置。 |
| 经济战和未来缺牌 | 立即扣分按 VP 基准全额折算。未来缺牌仍按预计补牌次数和 0.6 的兑现比例估算。时限和双方距离获胜所需的分差仍影响展望长度。 |
| 建设、招募、战斗及空军行动 | 现有估值按行动基准的比例表达。A 的建陆、建海分别为 0.8、0.7 次行动。B 估算手中建陆、建海牌的能力分别为 0.5、0.4 次行动。纸面当场执行和手牌潜力保留各自的比例，同一种动作的原生与卡牌声明写法共用评分。 |
| 手牌、可确定的抽牌和支付 | 牌的基础库存按张数换算，牌效潜力另加。A 出牌扣一张牌的基础分，B 从结算前后手牌变化体现，同一次消耗计一次。主动换牌中的拥挤、保留和弃置权重以卡牌基准表达。 |
| 基础牌稀缺 | 弃牌时继续追加 `1.2 × 已打出的同类牌数 ÷ 固定编组同类牌数 × 卡牌基准`。常规出牌沿用既有处理。 |
| 状态牌 | 沿用有效时机、触发概率、剩余时间、同一时机的竞争和防重复计算。单次效果能按 VP、牌数或可用行动换算时使用对应基准。 |

## 保留原值，待明确含义后调整

| 位置 | 当前保留的假设 |
| --- | --- |
| 手牌或未细分效果的兜底 | 未知暗牌在基础库存之上另有 0.20 的牌效估值，未知纸面效果通常取 0.20 或 0.25。被收录但尚无专门公式的效果仍用配置中的估值。 |
| 交战和目标的补充分 | 单位类型的额外移除价值、旧战斗分 `battle_target`，以及通用地点选择的有驻军加 0.25。现有值无法确定对应多少 VP、牌或行动。 |
| 状态牌及牌序的局势差异 | 整理牌库顶每张 0.22，送至牌库底每张 0.28，尚无预计损失时自磨每张扣 0.06。准备就绪的规则修正加 0.35 或增援加 0.20 的估计也沿用原值。 |

距离、补给、友军密度、威胁和触发概率继续作为系数。强制选择、可跳过选项和确认按钮的排序值仍用于流程控制。
