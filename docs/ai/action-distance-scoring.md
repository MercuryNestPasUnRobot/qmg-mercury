# 行动机会与分点评分 · v1.15

A、B 与玩法验证台共用 [AI 评分配置](../../core/data/ai_test_weights.json) 的 VP、卡牌和行动机会基准。默认值仍为 1、1、2。`capture_rounds` 是计算占点基础分时的起始回合数，默认 2。

## 地图

设分点每轮收入为 `VP`，距离为最短路径格数。

- **占点基础分** = `两轮 VP − 一次行动机会 + 最近剩余敌军到该分点的格数 × 行动机会分`。上限为该席仍可计分的轮数乘每轮 VP。没有可达敌军时取此上限。假定已经完成占领，原驻该点的敌军从这次距离估计中排除。常规 2 VP 分点，敌军距一格时值 4 分，距两格时值 6 分。
- **半分点**：斯堪纳维亚、北非和夏威夷每个有资格计分的陆海军单位各获 1 VP，并照常提供补给。A 先取同位置常规 2 VP 分点的占领价值，再乘 `实际每轮 VP ÷ 2`。B 通过 Core 获取每个已留存部队的下一次收入。美国开局在本土和夏威夷各驻一支陆军。美军在夏威夷组建必须有相邻的有补给美军陆海单位，即使是卡牌指定的征召也遵守此条件。
- **距离分** = `占点基础分 − 到该点的格数 × 行动机会分`。例如基础分 4 时，零格、 一格、两格分别为 4、2、0；低于 0 的分点不纳入。系统使用实际基础分与行动基准计算每次评估的范围。候选分点上限取配置中的 `route_forecast.nearest_sites`，当前为 4。
- **沿途单位**：到分点更近且在任一条最短路径上的单位，按其控制席适用的每轮 VP 和威胁距离求值，取距离分的一半。友军扣分，敌军加分。目标就是分点时也计点内已有单位，半分点上的友军不分摊新单位的收入。每个物理单位跨多个分点只计绝对影响最大的一次。调整后每个分点的最低分为 0。
- **移除单位**：每移除一个敌军单位，基本收益等于一次行动机会。A 另计该单位原占位置，以及移除它后持有方失去的状态牌给分。B 核对结算后的单位留存和下一次计分阶段的收入。常规共享分点继续每个合格席位各得 1 VP。

## 出牌和状态牌

取消普通出牌的初始扣分。移除负分触发的常规主动弃牌条件。回合必须出牌、无牌可弃实际扣 1 VP、支付和实际受损照原规则处理。已有实际获益的弃牌触发仍可参与选择。

| 效果 | 评分 |
| --- | --- |
| 空降建设 | 按能落在分点相邻区域的合法建设目标，取最高的 `分点基础分 − 一次行动机会分`。明确支付的手牌另计。 |
| 看牌库顶 | 单次查看 1 张值 `0.3 × 卡牌基准`。每轮免费发动的效果按剩余可用次数累加，空牌库没有可看牌的收益。 |
| 整理牌库顶 | 可整理至少两张时，一次估算为 `max(1, 剩余可用回合 × 0.25) × 卡牌基准`。使用公开牌数与自身合法选项。 |
| 返牌 | 每张返还的牌值 `1 × 卡牌基准`，使用时支付的牌另计。模拟能区分从牌库抽取的牌和回到牌库的牌，普通抽牌照库存变化计。 |
| 打一造一、造一打一等额外行动 | 根据本席可见手牌中能触发的张数加 1，乘以 `每次额外行动分 − 每次支付`。每个额外建设或攻击计一次行动机会。保留还来得及发动的回合和同一时机的触发竞争。 |
| 改变连线 | 从连线两端找距离最近的一支己方单位和一支敌方单位，分别算同一单位在改线前后的地图分差。并列时取绝对变化最大的一支。两阵营分差合并一次。 |
| 提供或取消分点 | 各取离该点最近的一支己方和敌方单位，用双方的距离分之差估价。并列时取影响最大的一支。移除该点时反向计算。仅针对特定国家或阵营的修改，在对应范围内估值。 |
| 地区给分 | A 在同一地域先计算常规 2 VP 分点的基础分，再乘 `该牌每轮提供的 VP ÷ 2`，然后照常扣每格行动距离。基础为 6 分时，占领给 1 VP 的地区值 3 分。建设与移除按合格驻军和得分阵营计算差值。B 用留存局面的实际条件及卡面 VP 核算下一次计分，计入符合条件的自动得分，以及最多一个可免费发动的可选得分响应。 |
| 补给、保护和规则豁免 | 保留旧估值的相对权重。常规支援以 `0.55 × 行动基准 + 0.65 × 当地分点基础分` 计算，战斗目标的行动系数为 0.425。只提供笼统估值的效果按其原来的行动机会比例换算。 |

## 仍沿用旧评分的情况

- 全图单位数门槛、要求敌军始终缺席等状态条件仍按实际条件及其原有预测估值。经济战未来的缺牌收益继续按预计缺牌计价。
- 当前本地卡库含按地区给分的状态牌。启用或取消分点标记、单纯查看一张牌库顶等机制用合成卡和 Core 结算接口验证。
