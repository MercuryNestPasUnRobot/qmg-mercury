# 行动机会与分点评分 · v1.12

A、B 与玩法验证台共用 [AI 评分配置](../../core/data/ai_test_weights.json) 的 VP、卡牌和行动机会基准。默认值仍为 1、1、2。`capture_rounds` 是计算占点基础分时的起始回合数，默认 2。

## 地图

设分点每轮收入为 `VP`，距离为最短路径格数。

- **占点基础分** = `两轮 VP − 一次行动机会 + 最近剩余敌军到该分点的格数 × 行动机会分`。上限为该席仍可计分的轮数乘每轮 VP。没有可达敌军时取此上限。假定已经完成占领，原驻该点的敌军从这次距离估计中排除。常规 2 VP 分点，敌军距一格时值 4 分，距两格时值 6 分。
- **距离分** = `占点基础分 − 到该点的格数 × 行动机会分`。例如基础分 4 时，零格、 一格、两格分别为 4、2、0；低于 0 的分点不纳入。系统使用实际基础分与行动基准计算每次评估的范围。候选分点上限取配置中的 `route_forecast.nearest_sites`，当前为 4。
- **沿途单位**：到目标分点更近且在任一条最短路径上的同阵营单位扣其距离分的一半。敌军按同样幅度加分。目标就是分点时也计点内已有单位。每个物理单位跨多个分点只分配给绝对影响最大的一个。调整后每个分点的最低分为 0。
- **移除单位**：每移除一个敌军单位，基本收益等于一整次行动机会。A 另算该单位原占位置的价值，B 另算结算前后的地图变化。评估里的这笔收益不改变 Core 的实际 VP。共享分点继续按每个合格席位各得 1 VP 结算。

## 出牌和状态牌

取消普通出牌的初始扣分。移除负分触发的常规主动弃牌条件。回合必须出牌、无牌可弃实际扣 1 VP、支付和实际受损照原规则处理。已有实际获益的弃牌触发仍可参与选择。

| 效果 | 评分 |
| --- | --- |
| 空降建设 | 按能落在分点相邻区域的合法建设目标，取最高的 `分点基础分 − 一次行动机会分`。明确支付的手牌另计。 |
| 整理牌库顶 | 可整理至少两张时，一次估算为 `max(1, 剩余可用回合 × 0.25) × 卡牌基准`。使用公开牌数与自身合法选项。 |
| 打一造一、造一打一等额外行动 | 根据本席可见手牌中能触发的张数加 1，乘以 `每次额外行动分 − 每次支付`。每个额外建设或攻击计一次行动机会。保留还来得及发动的回合和同一时机的触发竞争。 |
| 改变连线 | 从连线两端找距离最近的一支己方单位和一支敌方单位，分别算同一单位在改线前后的地图分差。并列时取绝对变化最大的一支。两阵营分差合并一次。 |
| 提供或取消分点 | 各取离该点最近的一支己方和敌方单位，用双方的距离分之差估价。并列时取影响最大的一支。移除该点时反向计算。公开的分点标记和分点修正走同一距离算法。 |

## 仍沿用旧评分的情况

- 一般的补给、规则豁免、防止被移除和非额外行动的响应仍用之前的专项估值。若卡牌未提供新的分点标记，按地区条件或单位数给 VP 的状态牌继续按文字结算其 VP。
- 单纯看牌、把牌送回牌库顶或底仍需分别定义信息和补牌收益。现行规则只替换了整理牌库顶。经济战对未来补牌的影响继续按预计缺牌计价。
- 当前本地正式卡库有固定分点，没有启用或取消分点标记的实体卡。动态分点和显式分点修正用合成卡和实际 Core 结算接口验过。
