# AI 测试版评分与方案

`core-v1-preview` 固定在提交 `85061bb`。基础功能与六席出牌已经验收，完整规则和跨牌组合仍待验证。后续 AI 测试以该提交和固定卡库指纹为对照。AI 只通过席位的 `Observation`、合法指令及 `CoreAPI` 观察和操作。

## 局面评分

继续使用阵营视角和等效 VP。已确定的胜局优先，已确定的败局排在最后。其他结果用同一套评分比较，行动价值取一次完整结算前后的分差。

`局面值 = 实际 VP 差 + 预计地图 VP 差 + 卡牌潜力差 + 资源修正`

| 项目 | 测试版标准 |
| --- | --- |
| 实际 VP | 直接读 Core 的阵营累计分。赢棋判定先于所有权重，牌已兑现的分数只在这里出现。 |
| 地图未来 VP | 用 Core 计分规则确定当前各席位能从每个地点取得的 VP。按席位顺序列出每点未来最多 3 次计分机会，每经过一个国家回合乘 0.8。当前计分阶段已经入账的机会移出预测。附属力量通过所属行动席位计分。同一地点在一个席位的计分时点只算一次。 |
| 争夺与补给 | 驻守价值按当前控制、补给与敌我压力计算。区域距离、单位类型、补给和预备单位影响附近的争夺能力。无控制权的地点按一个潜在占领席位估值。补给节点的移除前后分差用于解释，后续模拟实际断补时由地图项体现。 |
| 卡牌潜力 | 未执行的牌按可用性和效果类型估值。组合效果按声明累加，互斥分支只取一个，重复步骤仍计入，条件未满足的步骤当前不给收益。已部署的持续能力按可用副本计。未知手牌采用统一的数量价值。 |
| 资源 | 处理尚未涵盖的牌库短缺。已花的手牌体现在卡牌项下降，已经扣掉的 VP 留在实际分。预备单位只影响扩张估值，驻守单位的现有价值保留。 |

测试配置在 [ai_test_weights.json](../../core/data/ai_test_weights.json)。前三次计分机会和 0.8 折扣是可校准初值。地图预测以当前驻守、补给和规则修正作快照，单位图距离是争夺的近似指标。卡牌潜力估计分支收益，具体是否合法、费用是否产生收益，由候选的实际结算决定。默认验收台仍使用原有配置，便于两版在同一游戏状态下比较。

## 三种方案

| 方案 | 主要思想 | 可行性和预期效果 |
| --- | --- | --- |
| A. 分阶段规则评分 | 从合法操作出发，按阶段估算即时得分、据点、补给及支付成本。出牌、响应、弃牌分别排序，按最优局部候选执行。 | 容易接入，成本随候选数增长，适合作为快速回退与对照。完整卡库开局样本中，简单优先级仅有 1/6 与同预算下的全候选模拟首选完全一致。预期能处理常见操作，涉及嵌套、反制和组合效果时容易漏判。 |
| B. 候选预选后完整结算 | 先按 A 保留少量候选和可用回退，再用 Core 跑完卡牌、选目标与响应。自己一方选较好续步，对可见对手选择用保守续步。用新版局面值复排。 | **推荐作为 AI 测试版主线。** 真实卡库的固定种子样本中，3 个预选加结束阶段将中位耗时从 3.96 秒降到 2.54 秒，6 个席位中保留了 5 个参照最优评分。另一个席位损失约 1.35 等效 VP，说明候选上限还需校准。预期能改善组合牌和即时反制判断。 |
| C. 抽样未知牌和响应 | 根据公开信息和已知牌组生成若干可能世界，各候选使用同一批样本。比较平均收益和不利响应下的损失，只有样本足够时改变 B 的排序。 | 两个同观察的合成世界都经 Core 结算。风险行动分别得 0、3 VP，安全行动总是 2 VP。等权时安全行动更好。预期减少对暗置牌过于乐观的出牌。抽样会将结算工作量近似乘以样本数，先用于离线研究，等投影和时延达标再接入交互。 |

A 借鉴 TripleA 将战斗、非战斗移动和采购分开处理，以及把地区收益和损失放到同一评价尺度的方法。[TripleA 阶段调度](https://github.com/triplea-game/triplea/blob/84ad0f7911d46d1c0fd37592606137e29e5f7ebe/game-app/game-core/src/main/java/games/strategy/triplea/ai/pro/AbstractProAi.java) · [TripleA 地区估值](https://github.com/triplea-game/triplea/blob/84ad0f7911d46d1c0fd37592606137e29e5f7ebe/game-app/game-core/src/main/java/games/strategy/triplea/ai/pro/util/ProTerritoryValueUtils.java)

B 与 C 参考 Forge 先用启发式筛选、用相同种子比较候选、在时间或样本不足时回退的方法。QMG 按可见信息和牌组约束生成可能世界，保存的真实暗牌、牌库顺序与随机数状态均不参与取样。离线抽样成熟后，再评估按信息集合组织搜索是否值得。[Forge 候选模拟](https://github.com/Card-Forge/forge/blob/9748ef2c96d18bcb55271e20e63c32bdee3e991c/forge-ai/src/main/java/forge/ai/simulation/FlatMonteCarloPicker.java) · [Forge 隐藏信息处理](https://github.com/Card-Forge/forge/blob/9748ef2c96d18bcb55271e20e63c32bdee3e991c/forge-ai/src/main/java/forge/ai/simulation/HiddenInfoShuffler.java) · [信息集搜索论文](https://eprints.whiterose.ac.uk/id/eprint/75048/)

## 可行性验收与后续目标

- **固定局面。** 检查立即胜利、计分前后、共享驻守、断补、支付、弃牌、再响应。隐藏状态不同而观察相同时，确定性策略输出相同。超过预算或无法由观察表示的候选标作未完成。
- **初始测量。** 每个候选最多展开 16 个结算选择节点。种子 31 的六席样本中，全候选完成 38/44，预选完成 24/24，最慢决策为 6.32 秒。另用种子 73，每席预选 4 个候选并保留结束阶段，保住 6/6 个参照最优评分，中位耗时从 2.68 秒降至 2.59 秒，全候选完成 27/36，预选完成 25/28。两组开局不同，需要同种子对照才能判断扩大候选数的收益。全候选参照也受每候选预算和观察边界限制。
- **交付标准。** 先让 A 可以在每种待决状态提供合法回退，再给 B 加全局时间预算。目标是在同机验证集里，正常决策 P95 不超过 2 秒，与宽预算参照相比至少保留 90% 的首选等效分。已知必胜指令、结算合法性和信息隔离单独验收。90% 与 2 秒是阶段指标，当前样本只说明可行性。
- **强度估计。** 预期 A 能完成基本对局，B 在复合牌和已知响应场景中更稳，C 的额外收益主要出现在暗置响应会改变结局时。后续用相同种子、对换轴心与同盟的成对对局测净 VP、失误率、耗时和胜负。开局小样本不用于估算胜率。
