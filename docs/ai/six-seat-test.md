# 六席 AI 对照测试

六席共用 Core 的合法指令和结算。每个种子运行两局。第一局 B 控制轴心三席，第二局 B 控制同盟三席，另外三席始终运行 A。两局使用相同卡库、权重和初始随机种子。不同操作可能在对局中消耗不同数量的随机数。对局运行到 Core 判定胜负或平局。指令上限用于中止异常局，触线会报错。

## 决策

- **A** 按当前阶段、指令类型、可见卡牌效果和目标地区进行规则排序。A 也是 B 的回退策略。
- **B** 预选最多三项并保留结束阶段作为比较项。每项应在 Core 中结算到没有待决选择，再按胜负、实际 VP、预计地图 VP、卡牌和资源的合计变化排序。超时后可以使用已完成的评分。模拟无法完成或没有可比较的指令时，执行 A 的首选。
- B 可以沿用当前席位的结算续步。当前版本、决策类型、操作类型和全体合法选项都吻合时，才把该续步绑定到当前合法指令。遇到其他席位的选择，或实际响应改变了选择窗口，按当前席位的策略重新决策。
- 选择阶段可执行 Core 推送的响应窗口。测试驱动只派发当前行动席或必需决定席，自由时点的可选插入暂时未纳入策略。
- **C** 只运行离线的合成暗置响应探针。在线对照仅启用 A 和 B。B 的模拟进程收到单席观察、该席根指令、权重和去掉初始实例表的静态规则。不可见牌用区内计数生成占位对象，随机数另行初始化。

## 运行与记录

从仓库根目录运行以下命令。更换输出目录可保留已有实验。去掉 `--catalog` 可用仓库内的合成数据检查流程。

```powershell
npm run core:ai-match -- --catalog ../local-content/baselines/core-v1-preview/content.sqlite3 --seeds 31 73 127 --budget-ms 1500 --width 3 --nodes 16 --output ../local-content/ai-tests/six-seat-v1
```

时间预算按一次决策计，包含观察、合法指令查询、A 排序和 B 搜索，提交指令及写入日志单独进行。模拟端在截止前返回的完整候选才参与比较。每个候选另受结算选择节点上限约束。进程调度和截止后的返回开销可能令实际耗时略超预算，汇总会计数。对局始终按同一组参数串行运行，机器负载和进程调度可能影响在时限内评分的候选。

每局生成独立 JSONL，每次决策记录规则分、候选分项、超时或未完成原因、选中指令、所用策略和耗时。汇总使用 B 视角的 VP 差，按阵营和同种子两局汇总胜负与 VP，并单独统计 A、B 的决策延迟。中位数与 P95 含强制指令和结算选择。实卡库及含指令详情的日志保存在忽略目录 `local-content/`。

已完成的对局会自动从日志复现并收录到本机的 [Mercury 录像台](replay.md)。可使用 `--name`、`--ai-version` 和 `--ai-note` 标注每个批次。

### 资源调配评分

在回合开头进入出牌阶段后，六个行动席可在正常出牌前调配一次。默认弃三张手牌，从自己的牌库找一张建立陆军、建立海军、陆战或海战牌入手，然后重洗牌库。已有状态牌可调整费用或允许从弃牌堆取牌。从弃牌堆取牌时保留原牌库顺序。机会对象使用后进入响应区，并通过回合末结算恢复。

`调配总分 = 常规出牌值 + 常规弃牌扣分 + 陆海储备变化`

A 沿用常规出牌和弃牌的规则分。B 在候选宽度允许时预留一个调配候选，先用手牌潜力选出一个代表方案，再在支付后的席位投影中用 Core 估算所得基本牌的常规出牌价值。B 实际调配时，只有合法选项仍吻合才沿用方案。取得的牌进入手牌，玩家保有正常出牌决定。模拟选用静态牌种代表，不包含真实牌库对象。

牌库储备按陆系（建陆、陆战）和海系（建海、海战）分开计算。取其中一系时，用该系的 `0.6 × [ln(1 + N − 1) − ln(1 + N)]` 做边际扣分。取最后一张约扣 0.42，库存越多每取一张扣分越小。从弃牌堆取牌的储备项为零。库存由固定卡表数量减去该席可见的库外牌得到，搜索中的真实候选只向有权完成选择的席位显示。

### 手牌保留评分 · v1.2

六席共用 `保留值 = 短期价值 − 0.55 + 基础牌储备补分 − 重复占位扣分`。短期价值按当前局面、可用效果和目标估算。建陆、建海、陆战、海战的储备价值至少为 0.73，所以第一张即使暂时用不上，也至少有 0.18 保留分。短期价值足够的基础动作多保留一张。手牌达到上限减一时，超出储备的同类基础牌才按重复数量扣分，手里基础牌越多，额外占位的扣分越大。

弃牌阶段按保留值由低到高处理，一次弃一张，每次重新排序，保留分等于零时保留。牌库先预留填补现有手牌空位的张数，只有还有牌可替换时才主动弃牌。开局与超手牌上限时按同一保留值从低到高支付强制弃牌。常规出牌也从 −0.55 起评，B 可以优先采用已验证会立即获胜的行动。

A 与 B 共用弃牌评分，取值来自席位可见的手牌、局面与牌库数量。Core 通过普通弃牌结算触发响应，随后在抓牌阶段补牌。逐步日志与录像的「AI 怎么选」会显示保留分、短期价值、初始负分、基础储备和重复扣分。

### 强制出牌与路线评分 · v1.3

带 `mandatory_turn_play` 的新版规则库要求消耗每轮的常规出牌机会。有可出的手牌时必须出牌，已经明确可消耗常规机会的状态能力也可由玩家发动。没有这两类动作时，选择一张手牌弃置。空手时以一次扣 1 VP 的结算消耗机会。回合末仍可主动弃牌，抓牌不足也照常计分。旧录像使用当时的规则库指纹。

A、B 打出手牌时只选纸面分最高的一档。B 在这一档内用模拟选择同分牌或结算目标，即使模拟分为负也要完成本回合的常规出牌。调配仍可在出牌前执行。纸面直接得分由每 VP 2 分降到 0.75，弃对方牌库顶的固定效果分由 0.65 降到 0.25。B 局面里的实际 VP 差仍按真实值计。

每个单位至多影响最近四个可达计分点。零至三格权重沿用 1、0.65、0.30、0.10。四格起每多一格乘 0.70。路线的每个中间友军单位乘 0.80、每个敌军单位乘 1.15，按势力控制者所属阵营识别友敌。起点和终点不重复计入。等长路线取影响系数较高的路线，等距据点按编号定序。A 的地区选择也按这四个可达点的距离和路线加权。

v1.3 沿用原先的状态牌估价。

### 动态经济评分 · v1.4

直接获得 1 VP 的纸面分从 0.75 起算。取「已过席位回合比例」和「距离胜利线的压力」中较高的一项，乘 `1 + 1.4 × 压力`。胜利线压力按双方中离胜利最近的一方计算。胜差线为 30 时，双方打平的分差压力是 0，任一方领先 29 时是 `29/30`。牌面明确达到即时胜差线时另加 4 分，给敌方送到胜差线则扣同样的分。B 的实际比分仍直接来自 Core。

磨牌按其额外制造的缺抽计分。有合法多国目标时，出牌估价取最有价值的目标，实际选择时按各国当下的牌库数量打分。要估计对手到终局会抽几张，先按规则剩余席位回合取上限，再用离胜利最近的分差，以每轮推进 4 VP 估计提前结束的时间。由该席位在这段时间的行动顺序，结合当前手牌空位和每回合正常出牌次数，估算补牌需求。

设目标剩余牌库为 `D`，预计还需要补 `N` 张，本次弃牌库顶 `K` 张。未来额外缺抽是 `max(0, N − max(0, D − K)) − max(0, N − D)`。纸面分和 B 的局面资源分都按缺抽 VP 的 60% 预估；超出实际牌库的张数若按牌效立即扣分，由规则实际结算，B 只把它记入已发生的 VP。

例如预计还需补 8 张时，20 张牌库被磨 2 张的缺抽价值是 0，9 张牌库被磨 2 张会多缺抽 1 次，值 0.60。若终局临近、预测只剩一次正常补牌，这两种牌库此刻都足够。评分只读取牌区数量、公开榜分及行动顺序，临时调整属于测试参数。

### 状态牌的有效时机 · v1.5

A 按部署后的合法时机、预计发动概率、发动净收益和同一时机的竞争评分。B 只给尚未兑现的时机估值。录像的「AI 怎么选」可以展开每张候选状态牌的估算。详细算法和读数见[状态牌评分方案](status-scoring-proposal.md)。

### 争夺计分点 · v1.6

六席共用一套扩张评分。以目标地区为起点，仍看最近四个可达计分点，按每个点的 VP、距离和沿途兵力估算价值。

| 距计分点 | v1.5 距离权重 | v1.6 距离权重 |
| --- | ---: | ---: |
| 在点上 | 1.00 | 1.60 |
| 一步 | 0.65 | 1.00 |
| 两步 | 0.30 | 0.50 |
| 三步 | 0.10 | 0.10 |
| 四步及以上 | 每多一步乘 0.70 | 每多一步乘 0.70 |

两步内的路线上，每个中间敌军单位乘 1.40，终点有敌方陆军或海军再乘一次 1.40。三步及以上沿用每个中间敌军乘 1.15。每个中间友军单位仍乘 0.80，包含同阵营的附属部队。

A 选建设、招募或战斗牌时，按 Core 给出的合法位置，取当前可执行行动最好的近距离目标。纸面加分为该目标价值的 45%，最多 2 分。打得到敌方陆军或海军的战斗，目标价值另加 0.70；空打的纸面扩张加分为零。友方正在计分、且点上和相邻地区均无敌方陆海军时，选址只计该点近距离价值的 35%。敌军抵近时恢复全额。前一步会改变局面时，后续目标留到实际选择时重估。状态牌提供的额外建设与战斗也会参考发生地点。

B 在结算后按双方仍能获得的计分机会估价，已控制计分点的未来收益比 v1.5 提高 25%。机会仍按各席位的计分时机、威胁和剩余回合折算。实际 VP 由 Core 在计分阶段记录。
