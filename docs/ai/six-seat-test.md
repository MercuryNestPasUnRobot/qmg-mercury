# 六席 AI 对照测试

六席共用 Core 的合法指令和结算。每个种子运行两局。第一局 B 控制轴心三席，第二局 B 控制同盟三席，另外三席始终运行 A。两局使用相同卡库、权重和初始随机种子。不同操作可能在对局中消耗不同数量的随机数。对局运行到 Core 判定胜负或平局。指令上限用于中止异常局，触线会报错。

## 决策

- **A** 按当前阶段、指令类型、可见卡牌效果和目标地区进行规则排序。A 也是 B 的回退策略。
- **B** 预选最多三项并保留结束阶段作为比较项。每条分支由 Core 处理完当前动作及其回应，才按 B 的结算评分比较胜负、实际 VP、可留存单位、下一次有资格领取的分点收入和实际卡牌变化。超时后可以使用已完成的评分。模拟无法完成或没有可比较的指令时，执行 A 的首选。
- B 可以沿用当前席位的结算续步。当前版本、决策类型、操作类型和全体合法选项都吻合时，才把该续步绑定到当前合法指令。遇到其他席位的选择，或实际响应改变了选择窗口，按当前席位的策略重新决策。
- 选择阶段可执行 Core 推送的响应窗口。测试驱动只派发当前行动席或必需决定席，自由时点的可选插入暂时未纳入策略。
- **C** 只运行离线的合成暗置响应探针。在线对照仅启用 A 和 B。B 的模拟进程收到单席观察、该席根指令、权重和去掉初始实例表的静态规则。不可见牌用区内计数生成占位对象，随机数另行初始化。

## 运行与记录

从仓库根目录运行以下命令。更换输出目录可保留已有实验。去掉 `--catalog` 可用仓库内的合成数据检查流程。

```powershell
npm run core:ai-match -- --catalog ../local-content/baselines/core-v1-preview/content.sqlite3 --seeds 31 73 127 --budget-ms 1500 --width 3 --nodes 16 --output ../local-content/ai-tests/six-seat-v1
```

时间预算按一次决策计，包含观察、合法指令查询、A 排序和 B 搜索，提交指令及写入日志单独进行。模拟端在截止前返回的完整候选才参与比较。每个候选另受结算选择节点上限约束。进程调度和截止后的返回开销可能令实际耗时略超预算，汇总会计数。对局始终按同一组参数串行运行，机器负载和进程调度可能影响在时限内评分的候选。

每局生成独立 JSONL，每次决策记录规则分、候选分项、超时或未完成原因、选中指令、所用策略和耗时。汇总使用 B 视角的 VP 差，按阵营和同种子两局汇总胜负与 VP，并单独统计 A、B 的决策延迟。中位数与 P95 含强制指令和结算选择。实卡库及含指令详情的日志保存在忽略目录 `local-content/`。

已完成的对局会自动从日志复现并收录到本机的 [Mercury 录像台](replay.md)。可使用 `--name`、`--ai-version` 和 `--ai-note` 标注每个批次。

### 初版资源调配评分 · v1.1

在回合开头进入出牌阶段后，六个行动席可在正常出牌前调配一次。默认弃三张手牌，从自己的牌库找一张建立陆军、建立海军、陆战或海战牌入手，然后重洗牌库。已有状态牌可调整费用或允许从弃牌堆取牌。从弃牌堆取牌时保留原牌库顺序。机会对象使用后进入响应区，并通过回合末结算恢复。

`调配总分 = 常规出牌值 + 常规弃牌扣分 + 陆海储备变化`

A 沿用常规出牌和弃牌的规则分。B 在候选宽度允许时预留一个调配候选，先用手牌潜力选出一个代表方案，再在支付后的席位投影中用 Core 估算所得基本牌的常规出牌价值。B 实际调配时，只有合法选项仍吻合才沿用方案。取得的牌进入手牌，玩家保有正常出牌决定。模拟选用静态牌种代表，不包含真实牌库对象。

牌库储备按陆系（建陆、陆战）和海系（建海、海战）分开计算。取其中一系时，用该系的 `0.6 × [ln(1 + N − 1) − ln(1 + N)]` 做边际扣分。取最后一张约扣 0.42，库存越多每取一张扣分越小。从弃牌堆取牌的储备项为零。库存由固定卡表数量减去该席可见的库外牌得到，搜索中的真实候选只向有权完成选择的席位显示。

### 手牌保留评分 · v1.2

六席共用 `保留值 = 短期价值 − 0.55 + 基础牌储备补分 − 重复占位扣分`。短期价值按当前局面、可用效果和目标估算。建陆、建海、陆战、海战的储备价值至少为 0.73，所以第一张即使暂时用不上，也至少有 0.18 保留分。短期价值足够的基础动作多保留一张。手牌达到上限减一时，超出储备的同类基础牌才按重复数量扣分，手里基础牌越多，额外占位的扣分越大。

弃牌阶段按保留值由低到高处理，一次弃一张，每次重新排序，保留分等于零时保留。牌库先预留填补现有手牌空位的张数，只有还有牌可替换时才主动弃牌。开局与超手牌上限时按同一保留值从低到高支付强制弃牌。常规出牌也从 −0.55 起评，B 可以优先采用已验证会立即获胜的行动。

A 与 B 共用弃牌评分，取值来自席位可见的手牌、局面与牌库数量。Core 通过普通弃牌结算触发响应，随后在抓牌阶段补牌。逐步日志与录像的「AI 怎么选」会显示保留分、短期价值、初始负分、基础储备和重复扣分。

### 强制出牌与路线评分 · v1.3

带 `mandatory_turn_play` 的新版规则库要求消耗每轮的常规出牌机会。有可出的手牌时必须出牌，已经明确可消耗常规机会的状态能力也可由玩家发动。没有这两类动作时，选择一张手牌弃置。空手时以一次扣 1 VP 的结算消耗机会。回合末仍可主动弃牌，抓牌不足也照常计分。旧录像使用当时的规则库指纹。

A、B 打出手牌时只选纸面分最高的一档。B 在这一档内用模拟选择同分牌或结算目标，即使模拟分为负也要完成本回合的常规出牌。调配仍可在出牌前执行。纸面直接得分由每 VP 2 分降到 0.75，弃对方牌库顶的固定效果分由 0.65 降到 0.25。B 局面里的实际 VP 差仍按真实值计。

每个单位至多影响最近四个可达计分点。零至三格权重沿用 1、0.65、0.30、0.10。四格起每多一格乘 0.70。路线的每个中间友军单位乘 0.80、每个敌军单位乘 1.15，按势力控制者所属阵营识别友敌。起点和终点不重复计入。等长路线取影响系数较高的路线，等距据点按编号定序。A 的地区选择也按这四个可达点的距离和路线加权。

v1.3 沿用原先的状态牌估价。

### 动态经济评分 · v1.4

直接获得 1 VP 的纸面分从 0.75 起算。取「已过席位回合比例」和「距离胜利线的压力」中较高的一项，乘 `1 + 1.4 × 压力`。胜利线压力按双方中离胜利最近的一方计算。胜差线为 30 时，双方打平的分差压力是 0，任一方领先 29 时是 `29/30`。牌面明确达到即时胜差线时另加 4 分，给敌方送到胜差线则扣同样的分。B 的实际比分仍直接来自 Core。

磨牌按其额外制造的缺抽计分。有合法多国目标时，出牌估价取最有价值的目标，实际选择时按各国当下的牌库数量打分。要估计对手到终局会抽几张，先按规则剩余席位回合取上限，再用离胜利最近的分差，以每轮推进 4 VP 估计提前结束的时间。由该席位在这段时间的行动顺序，结合当前手牌空位和每回合正常出牌次数，估算补牌需求。

设目标剩余牌库为 `D`，预计还需要补 `N` 张，本次弃牌库顶 `K` 张。未来额外缺抽是 `max(0, N − max(0, D − K)) − max(0, N − D)`。纸面分和 B 的局面资源分都按缺抽 VP 的 60% 预估；超出实际牌库的张数若按牌效立即扣分，由规则实际结算，B 只把它记入已发生的 VP。

例如预计还需补 8 张时，20 张牌库被磨 2 张的缺抽价值是 0，9 张牌库被磨 2 张会多缺抽 1 次，值 0.60。若终局临近、预测只剩一次正常补牌，这两种牌库此刻都足够。评分只读取牌区数量、公开榜分及行动顺序，临时调整属于测试参数。

### 状态牌的有效时机 · v1.5

A 按部署后的合法时机、预计发动概率、发动净收益和同一时机的竞争评分。B 只给尚未兑现的时机估值。录像的「AI 怎么选」可以展开每张候选状态牌的估算。详细算法和读数见[状态牌评分方案](status-scoring-proposal.md)。

### 争夺计分点 · v1.6

六席共用一套扩张评分。以目标地区为起点，仍看最近四个可达计分点，按每个点的 VP、距离和沿途兵力估算价值。

| 距计分点 | v1.5 距离权重 | v1.6 距离权重 |
| --- | ---: | ---: |
| 在点上 | 1.00 | 1.60 |
| 一步 | 0.65 | 1.00 |
| 两步 | 0.30 | 0.50 |
| 三步 | 0.10 | 0.10 |
| 四步及以上 | 每多一步乘 0.70 | 每多一步乘 0.70 |

两步内的路线上，每个中间敌军单位乘 1.40，终点有敌方陆军或海军再乘一次 1.40。三步及以上沿用每个中间敌军乘 1.15。每个中间友军单位仍乘 0.80，包含同阵营的附属部队。

A 选建设、招募或战斗牌时，按 Core 给出的合法位置，取当前可执行行动最好的近距离目标。纸面加分为该目标价值的 45%，最多 2 分。打得到敌方陆军或海军的战斗，目标价值另加 0.70；空打的纸面扩张加分为零。友方正在计分、且点上和相邻地区均无敌方陆海军时，选址只计该点近距离价值的 35%。敌军抵近时恢复全额。前一步会改变局面时，后续目标留到实际选择时重估。状态牌提供的额外建设与战斗也会参考发生地点。

B 在结算后按双方仍能获得的计分机会估价，已控制计分点的未来收益比 v1.5 提高 25%。机会仍按各席位的计分时机、威胁和剩余回合折算。实际 VP 由 Core 在计分阶段记录。

### 基础牌弃置与建设选址 · v1.7

建陆、建海、陆战和海战分别统计。每张成功打出过的同类牌计一次，按物理牌 ID 去重。直接弃置、为调配付款以及被磨掉的牌都不进入已用数。弃置成本为 `1.2 × 本局已用同类牌数 ÷ 该国固定编组的同类牌总数`。例如已打出 2 张、编组共 5 张，则弃掉一张同类牌多扣 0.48 分。手牌保留和调配付款都使用这项成本。

常规出牌分、B 的出牌模拟分以及调配所得牌的出牌估值都按牌效计算。调配总分改为出牌估值加弃牌代价。牌库中可选牌种仍用于判定调配的可能结果。AI 的用牌数量来自本席已完成的操作日志，固定总数来自规则目录。

建设或招募时，目标地区及其一格相邻地区每有一个同阵营单位，该目标对两格内分点的价值再乘 0.75。附属部队按所属阵营计算。B 在估算未控制分点的近距离扩张潜力时同样考虑友军密度。评分仍用已有距离衰减来估算远处分点。

### 按分点距离筛选建设惩罚 · v1.8

建设和招募只对两格内的计分点应用这项惩罚。逐个比较目标及其邻近友军到该分点的最短距离。友军一样近或更近时，该点的建设价值乘 0.75。比如目标距分点两格时，距分点三格的相邻友军不产生这笔惩罚。直接在空分点建造时，外围友军不压低该点的价值。

同一支友军如果同时符合多个分点，只给最近的一个符合条件的分点扣分。目标与两个分点同距时按分点编号决定归属。B 估算尚未控制分点的潜力时也用同样的筛选，并从计数中排除被估值的单位本身。

### 攻击与建设对称评分 · v1.9

对可移除的敌方陆军和海军，用敌方接回该单位的建设价值衡量它被移除的损失。估算时从可见驻军中排除目标单位，再用其所属势力的地图连线、分点、距离和友军位置代入同一套建设公式。多个可选目标按各自的损失排序。出牌时使用同样的近点加成比例和上限。

命中目标的基础陆战与建陆同为 1.60 分，基础海战与建海同为 1.40 分。没有可移除单位的战斗沿用原基础分。B 对实际结算前后的变化比较分值，并用更新后的纸面分筛选常规出牌候选。

### 共享分点与限时搜索 · v1.10

建设把落子后新增的本阵营分点收入计入当地目标评分。空分点带来新的收入，两个合格盟国共享的 2 VP 分点仍一共提供 2 VP。占用该点的第二席每回合能拿到 1 VP，同时原驻守席改领 1 VP。A 因此优先考虑能新增阵营收入的建设。B 用相同规则计算结算后的分点收益，建设目标超过三个时先按 A 的排序筛选，模拟前三个。

B 默认每次决策最多 3 秒。投影继续通过 Core 的命令和结算，省去完整快照哈希以及每步后重复生成的观察。接近时限时保留已完整计算的候选，工作进程可继续处理下次决策。没有完整候选时沿用 A 的排序。正式对局的日志仍带完整记录链。

### 统一评分基准 · v1.11

1 VP、1 张牌、1 次完整行动机会分别折算为 1、1、2 局势分。占领常规空分点把前两轮的 4 VP 计为固定收益，之后的持有收益仍按原逻辑预估。修改基准、评分公式及待定值见 [AI 评分基准](scoring-units.md)。

### 行动机会与分点评分 · v1.12

占点基础分随最近敌军距离变化，沿途单位的修正按单位去重。常规出牌取消初始扣分，移除敌军计一次行动机会。额外行动的状态牌按可见手牌中的触发机会加一次估算。[评分公式、边界与待定项](action-distance-scoring.md)

### 地区与牌库收益 · v1.13

按地区每轮给分及对分点收入的修改，按该收益相对 2 VP 分点的比例估值。补给、保护和规则豁免使用当前行动及分点基准。返牌每张值 1 分，看一张牌库顶单次值 0.3 分。[评分公式](action-distance-scoring.md)

### 结算评分与留存 · v1.14

A 的规则评分用于出牌和选项筛选，也用于搜索回退。B 使用独立的结算评分。分支中发生的动作与响应由 Core 一次走完，到没有待决选择时才比较结算结果。实际 VP、可留存单位、下一次合法计分可得的分点收入和实际卡牌变化分别计入。持续状态和未来缺牌的预测用于 A 筛选。

为验证无补给单位能否留存，B 在隔离局面中用 Core 执行必要的回合末阶段和唯一必需的选择。若无法确认，就从评分局面排除该单位并重新检查依靠它的单位。仍可在当前模拟结算中利用临时海峡完成合法操作。海峡本身没有单独加分，后续成果以派出的单位确实留存、取得 VP 或已完成的其他结算为准。A 对当前可核对的建设、征召目标只计算有补给的落子。

B 估价调配时，先在投影中支付，再按常规规则筛选支付后会打出的牌，收益以这次结算的实际变化计算。新增基本牌继续用静态卡牌代表与允许公开的库存数量构造。

### 半分点与阵营计分 · v1.15

斯堪纳维亚、北非、夏威夷的评分以每个驻军 1 VP 为准。A 用部队控制席可获得的 VP 计算沿途影响和攻击收益，也比较建设、移除前后的状态牌计分。B 在留存局面里直接查询各席下一次计分能得到的地图和公开状态牌 VP，并把它们按受益阵营计入分差。已经实际发生的得分由 Core 分别入账。

### 响应牌与增援牌 · v1.16.1

一次性延迟牌的收益先按可见局面和完整效果估算，基础估算不加触发概率。再按发动时机扣分，每晚一个本席回合扣当轮一个常规分点的收入，即 2 VP。当前已知可在本席稍后的阶段发动时，等待为零回合。无法预知的敌方行动按一回合估算。

实际发动时按窗口内的目标和支付估算即时收益。即时收益为零或负时放弃。若用当前手牌的一次已知合法建设、战斗或空军行动能带来下一窗口，且扣除同一等待成本后严格高于现在发动，则保留该牌。延迟估算最多检查一次已知手牌行动。等待估值相同则立即发动。A 和 B 使用同一窗口规则，B 的分支结果仍独立按已结算局面评分。日志与录像分别显示盖牌基础分、时间扣分、即时收益和找到的联动。

### 港口与剩余建造牌 · v1.17

仆从军驻守分点的基础价值照常估算，建设位置到分点每格扣两次行动机会，仆从军不产生额外扩张偏好。建造路线按陆海连接计算。海军下一步需要新建陆军提供港口时，路线多计一步，且可达范围消耗一张建陆牌。已有相邻同阵营陆军时无需额外建设。

扩张偏好为 `每个可达分点 × 0.25 VP`，可在 `expansion_preference` 修改。以拟建造或已留存的新单位为起点，用该国当前剩余的基础建陆、建海牌和预备役，找有可行建造路线的分点。已有补给的同国单位能接续路线。当前打出的建造牌从预算扣除。目的地逐点估算并去重，半分点也算一个，直接建到的点已由占点评分处理。各分点的可达路线可以共用手牌预算。A 把偏好纳入出牌和选址。B 只在已结算且单位可留存时，按结算后的手牌和地图计算一次。

### 叠加分点与地区状态牌 · v1.18

同一个友军可分别扣减多个分点。最短路上更近的友军及等距友军都参与计算，每条分点规则最低为零。距离评分取消敌军驻守的正加成。实际移除敌军仍独立估算收益。

固定地区计分状态牌成为由状态区卡牌产生的隐分点，离场或被停用时撤下。普通点、半分点和隐分点各自按条件结算，且各有独立的金额。隐分点没有供给能力。按单位、按地区、任选一区一次和指定地区无敌军四种资格继续按卡面处理。放置多个来源时，计分检查会逐项结算，不消耗主动玩家的响应名额。A 对叠加在同一地点的分点共用一个距离名额，状态牌部署按当前盘面在预计计分轮内的重复收益估算。B 直接使用 Core 核算后的实际收入。

本版规则移除哈萨克斯坦和俄罗斯地区之间的直接连线。

### 回合末弃牌与过牌收益 · v1.19

回合按出牌、空军、补给、计分、弃牌、摸牌推进。当前国在弃牌阶段内至少有一张手牌进入其弃牌堆，即可免除该回合的扣分。完全未弃牌时，Core 在进入摸牌阶段前结算 −1 VP。超过手牌上限时的弃置也满足条件。历史录像按保存时的规则目录复现。

A 和 B 在弃牌阶段共用手牌估值。弃牌评分包含放弃该牌的成本、可触发的弃牌效果，以及第一次弃牌避免的 1 VP。相对直接结束弃牌阶段，每多能摸一张牌，加 `1 − 当前手牌平均短期收益` 分，允许为负。估算只使用可见手牌和本国牌库张数，并先为原本应补抽的空位留足牌。每次弃牌结算后按剩余手牌重新估值。录像中可查看过牌分、免扣分和实际扣分。

### 征召与回合末留存 · v1.20

主动打出含征召的牌或发动该类状态牌时，A 在该席公开观察的投影中走完卡牌效果，确定后续动作实际能否发生。已核实的己方续步仅在实际选项与投影窗口匹配时采用。B 继续用结算后的结果评估分支。手牌与牌库的未知内容始终用不带牌效的占位表示。

结算验证到当前回合的清理结束。留存部队照常计分。临时占住海峡或提供港口本身没有得分，只计已经完成的建造、战斗、一次性 VP 等收益。若后续舰队也在清理中被移除，舰队不产生留存分。回合内实拿的地点 VP 可单独计入，已由留存部队覆盖的收入只计一次。无法在限时内确认的分支不给推测收益。
